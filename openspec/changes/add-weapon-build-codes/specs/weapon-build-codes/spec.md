## Purpose

改枪码管理让陪玩把《三角洲行动》的武器配装方案码（改枪码）集中存储在账号下，自动解析出武器名称与适用模式，方便随时查看、搜索并一键复制使用，数据随账号云端同步。

## ADDED Requirements

### Requirement: 改枪码录入与格式解析

系统必须（SHALL）支持完整码「枪名-模式-编码」与仅含核心编码的改枪码。完整码从右侧解析，保留枪名中的连字符；核心码需补充武器与模式。枪名为1至100字符，模式为「全面战场」或「烽火地带」，核心编码为8至64位 ASCII 字母数字，原码最多256字符，备注最多2000字符。完整码自动带出武器名称与模式；非法输入明确提示，不保存。系统不要求反解配件或精校。

#### Scenario: 合法改枪码自动解析

- **WHEN** 用户录入 `PTR-32突击步枪-全面战场-6EIAKTC02U9HU6AC38CQJ`
- **THEN** 系统解析出武器名称「PTR-32突击步枪」、模式「全面战场」，允许用户补充备注并保存

#### Scenario: 非法格式拒绝保存

- **WHEN** 用户录入非法核心编码，或完整码模式不是「全面战场」或「烽火地带」，或核心码未补充武器和模式
- **THEN** 系统提示具体错误原因，不保存该条数据

### Requirement: 改枪码列表与搜索

系统必须（SHALL）以列表展示当前账号的全部改枪码，每条显示武器名称、适用模式和备注。必须支持按武器名称或备注关键字搜索，并支持按适用模式筛选。

#### Scenario: 关键字搜索

- **WHEN** 用户输入关键字「PTR」
- **THEN** 列表只显示武器名称或备注包含该关键字的改枪码

#### Scenario: 按模式筛选

- **WHEN** 用户选择只看「烽火地带」
- **THEN** 列表只显示该模式下的改枪码

### Requirement: 一键复制

系统必须（SHALL）为每条改枪码提供一键复制所保存原文的能力，支持完整码与核心码；复制失败必须明确提示，并允许选择文字手动复制。

#### Scenario: 复制完整改枪码

- **WHEN** 用户点击某条改枪码的复制按钮
- **THEN** 所保存的改枪码原文写入剪贴板，并给出复制成功反馈

### Requirement: 编辑与删除

系统必须（SHALL）允许用户修改已保存改枪码的码内容与备注，修改码内容时重新执行格式解析与校验。必须允许删除改枪码，删除前需用户确认，删除后不可恢复。

#### Scenario: 修改码内容重新校验

- **WHEN** 用户把某条改枪码的码内容改为非法格式
- **THEN** 系统提示错误并保留原数据不变

#### Scenario: 确认删除

- **WHEN** 用户删除一条改枪码并确认
- **THEN** 该条数据被移除，列表中不再出现

### Requirement: 云端同步与账号隔离

系统必须（SHALL）把改枪码存储在服务端并按账号隔离：用户只能读写自己账号下的改枪码，登录任一设备均可访问同一套数据。服务端的写入校验规则必须与客户端解析规则一致。

#### Scenario: 跨设备访问

- **WHEN** 同一账号在另一台设备登录
- **THEN** 该账号已保存的改枪码完整可见

#### Scenario: 账号间隔离

- **WHEN** 用户请求不属于自己的改枪码数据
- **THEN** 服务端拒绝访问，不泄露其他账号的数据

### Requirement: 供应商属性查询和缓存

系统必须（SHALL）仅从后端使用配置的 Token 查询三角洲数据帝 V2 服务，按武器和模式分页获取目录并在数据库缓存6小时；不得将 Token 发送至桌面客户端或写入版本控制文件。仅在核心码、武器、模式均一致时显示来源属性，保存来源、真实获取时间和参考价；不展示供应商声明不准确的 `zb`。私人改枪码仅存 PostgreSQL。

#### Scenario: 已收录码获取属性

- **WHEN** 用户查询或保存改枪码且目录准确匹配该方案
- **THEN** 系统保存和展示枪支属性、来源、获取时间与参考价格，同武器同模式的后续查询使用未过期缓存

#### Scenario: 未收录或供应商不可用

- **WHEN** 方案未收录、服务失败或未配置 Token
- **THEN** 系统反馈对应查询状态，仍允许保存私人改枪码，不把基础枪械属性冒充方案属性

#### Scenario: 模式与账号隔离

- **WHEN** 两个账号查询同武器和同模式，或用户切换方案模式
- **THEN** 公共目录缓存可复用但私人码和备注仍按账号隔离；不同模式独立缓存，不能串用方案属性
