## Why

陪玩在打单过程中会积累大量《三角洲行动》改枪码（武器配装方案码），目前散落在聊天记录、备忘录里，查找和复制都不方便。用户希望应用内有一个独立的改枪码管理页，集中存储自己的改枪码，能快速查看方案属性并一键复制，且数据随账号云端同步、多设备可用。

## What Changes

- 新增「改枪码管理」独立页面（桌面端侧边导航新入口）：改枪码的录入、列表查看、搜索筛选、编辑、删除。
- 支持完整码（`枪名-模式-编码`，枪名可含连字符）与核心码。完整码自动带出武器名称和模式，核心码需补充武器和模式；非法输入明确提示。
- 列表展示每条方案的武器、模式与备注说明，支持按武器名/备注搜索、按模式筛选，并提供一键复制完整改枪码。
- 改枪码数据存储于服务端（services/api + PostgreSQL），按账号隔离，随登录账号云端同步；提供增删改查 REST 接口。
- 接入三角洲数据帝改枪码 V2 服务，按武器与模式查询目录，准确匹配方案后保存属性、来源、查询时间和参考价格；未收录或查询失败时仍允许保存。不承诺任意编码解码。
- 私人改枪码和供应商公共目录缓存仅存 PostgreSQL，不增加 OSS 归档。

## Capabilities

### New Capabilities

- `weapon-build-codes`: 改枪码管理——改枪码的云端存储、格式解析（枪名与模式）、列表查看与搜索、一键复制，按账号隔离。

### Modified Capabilities

（无）

## Impact

- **服务端**：`services/api` 新增改枪码模块（路由 + SQLx 查询），PostgreSQL 新增 `weapon_build_codes` 表（随启动迁移执行），数据按账号隔离。不涉及金额、入账、退款，对账本余额口径无影响。
- **桌面端**：`apps/desktop/src/renderer` 新增页面组件与样式，`App.tsx` 增加导航入口，`api.ts` 与 `shared/contracts.ts` 增加类型与接口封装。
- **契约**：`apps/desktop/src/shared/contracts.ts` 新增改枪码相关类型；服务端需同步校验规则（格式校验、字段长度限制）。
- **部署**：数据库迁移随 API 启动执行；后台配置 `BUILD_CODE_API_TOKEN`。真实 Token 仅写入忽略的本机 `.env`，源码、示例与桌面客户端不包含凭证。
