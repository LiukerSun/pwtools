# match-recording Specification

## Purpose

记一场是陪玩对每次服务的记录。本能力定义手工与截图两种录入方式共用的结果模型（原值、假账扣除、净带出）、入账确认语义、幂等保存，以及入账后的修改与删除重算。

## Requirements

### Requirement: 记一场入口与共用结果

系统必须（SHALL）在订单内提供「记一场」作为记录入口，顶部直接显示已确定的老板和订单。默认导入截图，可切换手工填写，两种方式始终共用同一份结果；截图导入后改为手填仍校对同一张图，不生成重复流水。小时单可直接填写时长并提供常用时长快捷填写；录入方式切换保留当前已填写结果。保存后仍停在原订单。

#### Scenario: 方式切换保留结果

- **WHEN** 用户在记一场中已填写或识别出结果，再切换截图/手工录入方式
- **THEN** 当前结果保留，不丢失也不复制

#### Scenario: 保存后停留原订单

- **WHEN** 用户确认入账保存成功
- **THEN** 界面仍停留在原订单，可继续记下一 场

### Requirement: 假账扣除与净带出

系统必须（SHALL）对金额场次分别保存带出原值、假账扣除和净带出。假账扣除必须明确填写，没有假账也需填 0，取值范围为 0 至原值之间；识别值不会直接扣账。净带出 = 原值 − 假账扣除，为非负金额，用于判断单局达标和确认护航进度。失败的场次计入完成量为 0，但保留物资原值和净值用于标准判断。金额上限为 9,000,000,000,000，备注最多 1000 字。

#### Scenario: 扣除后净计入

- **WHEN** 一场原值 1,867,449，假账扣除填写 500,000
- **THEN** 系统保存三者并按净带出 1,367,449 计入进度

#### Scenario: 无假账填零

- **WHEN** 金额场次没有假账
- **THEN** 用户必须明确填写扣除 0 才能入账

#### Scenario: 失败保留原值

- **WHEN** 一场撤离失败
- **THEN** 完成量计入 0，原值与净值仍保留用于判定标准核对

### Requirement: 确认入账语义

系统必须（SHALL）只在用户「确认入账」并保存成功后才更新订单进度并长期保存记录；识别结果本身不直接扣账。保存失败保留填写内容。等待服务端保存成功后才更新界面。截图只有已确认才进入账本；重复上传或确认不重复扣账；修改、撤销确认或删除截图会重算订单余额。

#### Scenario: 确认才入账

- **WHEN** 截图识别完成但用户尚未确认入账
- **THEN** 订单进度不变，记录处于待确认状态

#### Scenario: 保存失败保留内容

- **WHEN** 确认入账时服务端保存失败
- **THEN** 系统提示失败并保留已填写内容，可重试

#### Scenario: 删除重算

- **WHEN** 用户删除一条已入账记录
- **THEN** 系统删除该记录并重算订单的已完成与还欠

### Requirement: 幂等保存

系统必须（SHALL）保证同一笔提交在服务器已提交但响应断开或 JSON 无效时，经限流重试也只产生一条流水：客户端保留同一幂等请求重试核实，不重复入账。

#### Scenario: 响应丢失重试

- **WHEN** 保存请求已被服务器处理但响应丢失，客户端重试
- **THEN** 服务端核实后返回同一结果，账本中只存在一条流水

### Requirement: 场次时间

系统必须（SHALL）允许为每场记录填写场次时间，点击整个输入框打开中文日历，支持小时分钟、「现在」和清空；时间按北京时间保存，留空则使用入账时间。日历打开时按 Esc 只关闭日历，记场内容继续保留。

#### Scenario: 留空用入账时间

- **WHEN** 用户不填写场次时间直接入账
- **THEN** 该场时间按入账时间（北京时间）保存

#### Scenario: Esc 只关日历

- **WHEN** 日历打开时用户按 Esc
- **THEN** 仅关闭日历，已填写的记场内容保留

### Requirement: 哈夫币汇率计算

系统必须（SHALL）提供哈夫币汇率计算：输入订单价格（元）、保底金额（W）和陪玩实际到手百分比，按 `订单价格 ×（抽成 ÷ 100）÷ 保底金额 × 1000` 实时计算每 1000W 的人民币到手金额，同时显示本单到手金额和订单原价汇率。价格和保底必须大于 0，抽成范围 0–100%，结果保留两位小数。切换页面保留本次输入，支持清空；退出账户后清除。

#### Scenario: 汇率换算

- **WHEN** 输入订单 200 元、保底 2500W、抽成 80%
- **THEN** 显示本单到手 160 元、每 1000W 到手 64 元、订单原价汇率 80 元/1000W

#### Scenario: 非法输入

- **WHEN** 价格或保底不大于 0，或抽成超出 0–100%
- **THEN** 系统提示输入无效，不产生误导性结果
