# desktop-capture Specification

## Purpose

Windows 客户端提供从桌面直接采集战绩截图的入口：全局快捷键唤起屏幕框选，支持窗口吸附与自由框选，截图后选择老板与订单进入识别校对流程。

## Requirements

### Requirement: 全局导入快捷键

系统必须（SHALL）提供全局快捷键启动截图，默认为 Ctrl + Alt + A。快捷键可在设置中更改或清除，保存在当前设备；绑定冲突时保留之前的绑定；退出登录不清除该偏好。

#### Scenario: 默认快捷键唤起

- **WHEN** 用户在任意界面按下 Ctrl + Alt + A（未自定义时）
- **THEN** 客户端进入截图流程

#### Scenario: 冲突保留旧绑定

- **WHEN** 用户设置的新快捷键与已有绑定冲突
- **THEN** 系统保留之前的绑定并提示，不静默覆盖

### Requirement: 窗口吸附与自由框选

系统必须（SHALL）在截图时先最小化/隐藏主窗口并冻结桌面，按 Z 顺序读取可见顶层窗口供吸附：跳过最小化、隐藏、其他虚拟桌面、PWTools 自身及桌面/任务栏窗口；DWM 可见边界裁切至虚拟桌面并转换为本地物理像素，多屏负坐标与缩放按一物理像素对应一 CSS 像素处理。鼠标悬停自动吸附窗口，单击选中整窗；按住移动至少 5 像素切换为自由框选。选中后可拖动边框微调；双击、Enter 或工具栏确认；「重新选择」或 Backspace 回到预选；Esc 或右键取消。

#### Scenario: 单击选窗

- **WHEN** 用户悬停某可见窗口并单击
- **THEN** 系统选中该窗口整窗区域，可继续微调或确认

#### Scenario: 拖动自由框选

- **WHEN** 用户按住并移动至少 5 像素
- **THEN** 切换为自由框选，框选后沿用微调与确认工具

#### Scenario: 取消不上传

- **WHEN** 用户按 Esc、右键或超时
- **THEN** 截图取消，不上传任何内容，恢复原有窗口状态

### Requirement: 截图后流程

系统必须（SHALL）在截图确认后恢复主窗口，让用户选择老板与护航/单局订单，再上传识别并核对。选区 PNG 在内存中生成，不读写系统剪贴板；截图过程中阻止重复触发及退出。托盘状态下取消截图保持隐藏，完成截图恢复窗口。

#### Scenario: 选单上传

- **WHEN** 用户完成框选并确认
- **THEN** 系统恢复窗口并提示选择老板与订单，随后沿用识别与入账流程

#### Scenario: 托盘取消

- **WHEN** 主窗口处于托盘隐藏状态时截图被取消
- **THEN** 窗口保持托盘隐藏，不意外弹出

### Requirement: 文件与粘贴导入

系统必须（SHALL）在订单「记一场」中支持点击选择文件和按 Ctrl + V 粘贴图片。粘贴沿用文件选择的类型、大小校验、原图上传和识别流程；连续粘贴不重复上传，已有原图不被替换，上传结果不确定时仅可重试原图；普通文字和手工模式继续使用正常粘贴。

#### Scenario: 粘贴上传

- **WHEN** 用户在截图录入界面复制过图片并按 Ctrl + V
- **THEN** 系统按文件上传流程处理该图片并进入识别校对

#### Scenario: 重复粘贴

- **WHEN** 用户连续粘贴同一张图
- **THEN** 不重复上传，已有原图保持不变
