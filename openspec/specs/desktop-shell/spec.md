# desktop-shell Specification

## Purpose

Windows 客户端的桌面外壳行为：托盘运行与关闭偏好、自定义标题栏与窗口交互、主题与可访问性适配，保证记账操作在窄窗口和不同系统设置下都可用。

## Requirements

### Requirement: 托盘运行与关闭偏好

系统必须（SHALL）在第一次关闭窗口时询问是否在系统托盘运行，可选择托盘运行、退出应用或取消，之后记住选择；设置中可随时更改关闭方式。托盘运行隐藏窗口和任务栏按钮并保留填写内容，点击托盘图标恢复，右键菜单可打开或完整退出。标题栏最小化按钮仍使用普通任务栏最小化。旧版已开启后台运行的用户升级后首次确认。真正退出时继续检查未保存修改和待核实保存结果。

#### Scenario: 首次关闭询问

- **WHEN** 用户首次点击关闭
- **THEN** 系统询问托盘运行、退出应用或取消，选择被取消时保持窗口打开

#### Scenario: 托盘恢复

- **WHEN** 应用处于托盘运行，用户点击托盘图标
- **THEN** 窗口恢复并保留之前填写的内容与最大化状态

#### Scenario: 退出保护

- **WHEN** 用户选择完整退出且存在未保存修改或在途保存
- **THEN** 系统提示并等待处理，不直接丢弃内容

### Requirement: 自定义标题栏与窗口行为

系统必须（SHALL）提供原生自定义标题栏与可折叠侧边栏。启动时窗口按当前屏幕工作区居中并考虑屏幕缩放与任务栏。无边框窗口保留可调整大小的边缘（随 DPI 缩放），最大化时页面铺满，恢复后重新启用边缘；最小尺寸为页面保留 960×640 逻辑像素，屏幕工作区不足时以工作区为上限。重复启动唤回已运行的同一实例窗口。

#### Scenario: 启动居中

- **WHEN** 用户正常启动应用
- **THEN** 窗口在当前屏幕工作区内居中显示

#### Scenario: 边缘缩放

- **WHEN** 用户拖动窗口四边或四角
- **THEN** 窗口按对应方向调整大小，受最小尺寸与工作区限制

### Requirement: 主题与可访问性

系统必须（SHALL）提供深浅色主题，主题与侧栏折叠偏好在当前设备保存，不随退出登录清除。界面遵循系统减少动态效果设置；布局适配窄窗口，保留键盘焦点可见性。页面切换、导航选中、展开、悬停、拖入截图、确认保存和图片缩放有交互动效，减少动态效果开启时相应收敛。

#### Scenario: 主题持久

- **WHEN** 用户切换深/浅主题后重启应用
- **THEN** 主题保持上次选择

#### Scenario: 减少动态效果

- **WHEN** 系统开启减少动态效果
- **THEN** 界面动效相应减少或停止自动播放
