# app-updater Specification

## Purpose

Windows 客户端内置自动更新：启动时检查服务器版本，用户确认后才下载安装。更新分正式与测试双通道，经 HTTPS 公开只读地址分发，全程校验大小与 SHA-256。

## Requirements

### Requirement: 启动检查与用户确认

系统必须（SHALL）在客户端每次启动时从当前 API 地址检查更新，发现新版后弹出版本号、更新内容及「立即更新 / 暂不更新」。检查只读取清单，用户选择更新后才下载安装包。暂不更新、关闭提示或按 Esc 均可继续使用，本次启动不再重复提示同一版本，下次启动仍会检查和提醒。「设置 → 版本更新」始终可重新发起检查与更新。已是最新版或检查失败时不自动弹窗。未登录也会收到提示并可选择更新。

#### Scenario: 发现新版提示

- **WHEN** 启动检查发现更高版本
- **THEN** 弹出版本号与更新内容，等待用户选择，未同意前不下载

#### Scenario: 暂不更新

- **WHEN** 用户选择暂不更新、关闭提示或按 Esc
- **THEN** 本次启动不再提示同一版本，下次启动重新检查

#### Scenario: 检查失败静默

- **WHEN** 启动检查失败或已是最新版
- **THEN** 不弹出更新窗口，应用正常使用

### Requirement: 下载与安装确认

系统必须（SHALL）在用户选择立即更新后显示下载进度，可切换后台下载；下载完成后仍由用户确认「退出并安装」或「稍后安装」。保存、识别、截图或未核实提交期间不允许安装，未保存修改继续使用原有离开确认。NSIS 等待发起更新的进程退出后安装到原程序目录，自动重新启动，不删除用户数据；升级保留账户、账本与本机偏好。

#### Scenario: 下载后确认安装

- **WHEN** 安装包下载完成
- **THEN** 用户选择「退出并安装」或「稍后安装」，系统不自动安装

#### Scenario: 有未保存内容

- **WHEN** 存在未保存修改、在途保存或截图操作时尝试安装
- **THEN** 安装被阻止并提示，原有草稿保护生效

### Requirement: 双通道与测试体验开关

系统必须（SHALL）在「设置 → 版本更新」提供「参与测试体验」开关，默认关闭，按本机资料目录保存。开启后同时检查正式与测试通道，选择版本号更高的版本；关闭后只检查正式通道并清除之前的测试版更新候选。下载或安装过程中不能切换开关。关闭开关不卸载当前测试版、不自动降级；后续有更高版本的正式版时正常提示。

#### Scenario: 开启测试通道

- **WHEN** 用户开启「参与测试体验」
- **THEN** 系统同时检查两个通道并提示版本号更高的候选

#### Scenario: 关闭测试通道

- **WHEN** 用户关闭开关
- **THEN** 只检查正式通道，清除测试版候选；当前测试版继续使用，不自动降级

### Requirement: 下载完整性校验

系统必须（SHALL）在下载后和安装前核对安装包的文件大小、SHA-256 及安装器 Windows 版本信息。更新器仅接受同一服务器的 HTTPS 地址（本机测试允许回环 HTTP），拒绝重定向。缓存位于 `%APPDATA%\PWTools\Updates`；失败可重试，已安装版本的缓存在后续成功检查时清理。

#### Scenario: 篡改拒绝

- **WHEN** 下载文件的大小或 SHA-256 与清单不一致
- **THEN** 系统拒绝安装并允许重试下载

#### Scenario: 重定向拒绝

- **WHEN** 更新地址发生重定向或非同一服务器 HTTPS
- **THEN** 更新器拒绝该响应

### Requirement: 发布通道约束

系统必须（SHALL）通过发布脚本分发安装包与清单：服务器再次核验 SHA-256，先完成版本文件再原子替换清单；拒绝低版本和同版本不同内容；已发布版本文件不可替换。`release-notes.json` 的 `channel` 为 `stable` 或 `beta`（省略默认正式版），同时决定安装程序版本标识、清单生成位置和发布目的地；发布脚本拒绝清单与通道不一致。所有版本使用递增的三段数字，测试标识作为独立通道字段保存。更新地址由 Openresty 公开只读提供，无需登录，清单禁止缓存。

#### Scenario: 通道不一致拒绝

- **WHEN** 发布清单的通道与 `release-notes.json` 不一致
- **THEN** 发布脚本拒绝发布

#### Scenario: 版本回退拒绝

- **WHEN** 发布版本低于已发布版本，或同版本内容不同
- **THEN** 服务器拒绝该发布
